Comment importer les séances dans Zwift
  1. Télécharge le .zip et décompresse-le.
  2. Tu peux aussi télécharger une seule séance : ouvre-la et appuie sur « Télécharger pour Zwift ». Le dossier ERG contient les mêmes séances en .erg (watts) et .mrc (% de FTP) pour les autres applis (TrainerRoad, Rouvy, MyWhoosh…).
  3. Copie les fichiers .zwo dans Documents › Zwift › Workouts › (ton numéro Zwift).
  4. Relance Zwift : les séances apparaissent dans Entraînements › Custom Workouts. Ton Van Rysel D500 en mode ERG tiendra les watts tout seul.
  5. Pour les tests FTP, utilise le test « Ramp Test » intégré à Zwift : il met ta FTP à jour automatiquement.
Comment envoyer le plan dans DOSSARD 971
  1. Appuie sur « Code pour DOSSARD 971 » : le code est copié. C'est un simple texte : depuis ton téléphone, envoie-le-toi par WhatsApp ou par mail pour le coller sur ton PC.
  2. Dans DOSSARD 971, ouvre Entraînements › Importer une séance, colle le code dans « Code WattPlan » et appuie sur « Charger le plan ».
  3. DOSSARD 971 affiche la séance du jour. Après un changement de plan (bilan, mot du coach, nouvelle FTP), recopie le code pour le mettre à jour.
  4. Sans copier-coller, tu peux aussi importer le .zip entier dans DOSSARD 971.
