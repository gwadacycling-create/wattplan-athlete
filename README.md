# WattPlan · page athlète

Page de l'athlète pour WattPlan : plan du jour, check du matin, bilan après séance et envoi du bilan au coach par WhatsApp.

Ouvrir : https://gwadacycling-create.github.io/wattplan-athlete/

Aucun compte n'est nécessaire. Les données restent dans le téléphone de l'athlète et ne sont envoyées au coach que par le message WhatsApp.
